# Claude Code Workbench — 升级设计方案

> 本轮升级的功能设计与分阶段开发计划。所有决策已与用户逐项确认。
> 最后更新:2026-10-22

## 1. 概述

在现有工作台(Phase 1–6 已完成)基础上,新增:语言切换、Git 历史版本管理、项目/Session 删除、Windows 打包与开源准备、聊天快捷指令与 Git 保存、头像设置。核心原则:**优先保证现有功能不被破坏,所有危险操作(写 Git、删文件)必须明确确认、可回退、防误删**。

## 2. 已确认的功能决策

### 2.1 语言切换
- 默认简体中文,不跟随系统
- Settings 页增加语言选项(与主题并列):「简体中文 / English」
- 切换后所有工作台 UI 文案即时生效,不需重启
- 存 `settings` 表(复用现有 key-value,key = `language`)
- 轻量内置翻译字典(zh/en),不引入 i18n 库
- 只翻译工作台 UI,不翻译 Claude 回复/项目文件/Skills 说明/Git 提交信息
- 翻译缺失回退简体中文,避免空白/undefined

### 2.2 Git 历史版本 + 切换
- **查看**:历史版本列表(commit hash 短 ID、提交说明、作者、时间);版本详情;代码文件可看 diff
- **切换规则**:
  1. 切换前检查工作区 + 暂存区
  2. 有未提交修改 → 阻止切换,列出变化文件,提供「查看修改 / 保存为 commit / 取消」
  3. 绝不自动 stash / discard / `git reset --hard`
  4. 工作区干净 → 允许切换,但先显示目标版本提交说明 + 时间,二次确认后执行
- 切换实现用 `git checkout <commit>`(detached HEAD 可回到原分支,方案实现时定)

### 2.3 删除项目
- **「从工作台移除」(默认)**:只删 `projects` 记录 + 关联 `sessions` 记录;不删磁盘文件夹、不改 Git;提示「文件仍保留可重新添加」;普通确认(不需输入名称)
- **「删除项目文件夹」(危险,单独入口)**:
  - 显示完整路径 + 警告会删整个目录(代码/文档/Git 历史)
  - 必须输入项目名二次确认
  - 有未提交 Git 修改 → 额外警告
  - 删除前拦截危险路径:工作台自身目录、用户主目录、磁盘根目录等
  - 不自动备份/移动/清空;失败保留记录并显示错误

### 2.4 删除 Session
- 确认框显示:会话标题、所属项目、session ID
- 只删 `sessions` 表记录,**绝不删 Claude Code 的 `~/.claude/projects/*.jsonl`**
- 不影响源代码/文件夹/Git 历史/其他 Session
- UI 标注「从工作台移除 Session」(避免误以为完整历史被删)
- 失败保留记录并报错;删除后可用 `--resume <id>` 找回

### 2.5 聊天快捷指令按钮(固定 5 个,按序)
1. `/simplify` — 整理简化当前代码
2. `/compact` — 压缩会话上下文
3. `/btw` — 临时提问/补充,不打断主任务
4. `/init` — 生成/更新 CLAUDE.md
5. `/diff` — 查看当前代码改动

- 每个按钮显示指令名 + 简短中文说明
- 点击先检查 stream-json 环境可用性,不可用显示友好提示(不卡住聊天)
- 遵循各自 Claude Code 语义,不擅自改命令
- `/init`、`/simplify` 可能改文件,执行前明确提示,不自动确认
- 已实测:`/compact`、skill 指令可用;`/help` 不可用;`/btw`、`/diff`、`/simplify`、`/init` 实现时实测

### 2.6 Git 新版本保存按钮
- 点击弹确认窗口,显示:项目 + 分支、待提交文件清单(区分新增/修改/删除)、代码文件 diff 入口、提交说明输入框(自动生成默认说明可改)
- 点「提交」才执行;提交前**再次检查文件状态**(防止窗口打开期间变化)
- 提交范围安全:默认只提交确认过的改动;不无提示 `git add -A`;未跟踪文件(尤其 `.env`/密钥/个人配置)必须提醒并让用户明确选择;已暂存文件明确显示会被提交;文件列表变化则取消提交并刷新
- 本地 `git commit`,**不 push**
- 成功显示提交说明 + 时间 + 短 commit ID,刷新 Git 状态;失败显示错误

### 2.7 头像设置
- 复制到 `userData/avatars/`,数据库存路径(不存二进制);用户/Claude 分开
- 更换:先存新图再更新路径,失败保留原图
- 只处理工作台自有头像文件,不删用户原图
- 文件名安全命名(如 uuid + 扩展名),不用原文件名
- 显示:聊天界面(用户消息旁用户头像,Claude 回复旁 Claude 头像);Settings 提供设置入口(预览/更换/恢复默认)
- 默认:用户=中性人形图标,Claude=工作台 Logo
- 恢复默认只清工作台自有头像文件与路径

### 2.8 Windows 打包 + GitHub 开源
- **打包**:electron-builder,NSIS 安装版(双击安装、可选位置、桌面+开始菜单快捷方式);暂不做 portable
- 数据存 Electron `userData` 目录(不在安装目录);卸载不默认删用户数据
- **图标**:先内置默认占位图标(生成 `.ico` + `.png`),素材集中放 `build/` 目录,不写死路径
- **许可证**:MIT,生成 `LICENSE`;版权信息用占位符,待用户确认作者信息
- **开源前清理**:移除 `better-sqlite3`、`@electron/rebuild`;移除 `.npmrc` 的 `electron_mirror`;检查 `.gitignore`(node_modules/out/dist/日志/临时文件/本地数据库);检查无本地路径/密钥/环境变量泄露;不提交用户项目内容/聊天历史/头像/API key
- **发布**:创建仓库、公开、首次 push 均需用户明确确认

### 2.9 系统托盘与关闭窗口行为
- **关闭窗口最小化到托盘**:点击窗口右上角 × 时,不退出进程,而是隐藏主窗口并在 Windows 系统托盘继续运行;不影响当前 Claude 会话与正在执行的任务
- **托盘交互**:图标用工作台应用图标;右键菜单至少含「打开工作台」(恢复主窗口)与「退出应用」(真正退出);双击图标也恢复主窗口
- **真正退出**:仅托盘「退出应用」才退出;退出前若 Claude 任务仍在运行,弹确认提醒「任务可能中断」;关闭窗口不终止 Claude 进程
- **设置开关**:Settings 提供「关闭窗口时最小化到托盘」开关,默认开启,存 settings(key = `minimizeToTray`)
- **国际化**:托盘菜单与提示支持 zh/en
- **平台**:兼容 Windows(Tray API + 图标);托盘图标复用 Stage 6 生成的占位图标

## 3. 数据存储变更

- 复用现有 `settings` 表(key-value),新增 key:
  - `language`(zh/en)
  - `avatar_user`(用户头像文件路径)
  - `avatar_claude`(Claude 头像文件路径)
  - `minimizeToTray`(关闭窗口时最小化到托盘,true/false,默认 true)
- 头像文件存 `userData/avatars/`,数据库只存相对/绝对路径
- `projects`、`sessions` 表结构不变;删除用现有外键 `ON DELETE CASCADE`(删 project 时自动删关联 session)

## 4. 新增 IPC(均经主进程 + preload 白名单)

| 通道 | 用途 | 风险 |
|------|------|------|
| `git:log` | 历史版本列表 | 只读 |
| `git:show` / `git:diff` | 版本详情 / 工作区 diff | 只读 |
| `git:checkout` | 切换版本(含工作区检查) | 写,需确认 |
| `git:commit` | 保存版本(add + commit) | 写,需确认 |
| `project:remove` | 从工作台移除 | 删记录 |
| `project:delete` | 删除文件夹(危险) | 删文件,需路径拦截 + 输入确认 |
| `session:delete` | 删除 session 记录 | 删记录 |
| `avatar:set` / `avatar:reset` | 头像设置/恢复默认 | 文件复制/删除 |
| `settings:get/set` | 已有,语言复用 | 无 |

## 5. 分阶段开发计划

### Stage 1:语言切换 + 头像(低风险,纯 UI + settings)
- 范围:抽取文案到翻译字典、语言状态管理(App 层)、Settings 语言选项;头像 IPC + 文件复制 + 聊天界面显示 + Settings 设置入口
- 验收:语言即时切换/重启保持/缺译回退;头像聊天显示/更换/恢复默认/重启保持
- 风险:文案抽取工作量大,需覆盖所有硬编码中文

### Stage 2:删除 Session(低风险)
- 范围:`session:delete` IPC + SessionsView 删除按钮 + 确认框
- 验收:确认框信息完整、删后消失、`.jsonl` 保留、失败报错

### Stage 3:删除项目(中风险)
- 范围:`project:remove` / `project:delete` + 危险路径拦截 + UI 分入口
- 验收:移除保留文件夹;删除文件夹需输入名称、路径拦截生效、失败保留记录

### Stage 4:系统托盘与关闭窗口行为(低-中风险)
- 范围:主进程 Tray 图标 + 菜单;拦截窗口 close 事件(最小化到托盘);托盘「退出应用」真正退出 + 活跃任务确认;Settings「最小化到托盘」开关(settings);托盘菜单 zh/en
- 验收:关窗最小化到托盘、会话不断;双击/菜单恢复窗口;退出前有活跃任务弹确认;开关生效且重启保持

### Stage 5:Git 历史版本(中高风险)
- 范围:`git:log/show/diff/checkout` + 历史列表 UI + diff 展示 + 切换安全流程
- 验收:历史正确;切换前工作区检查、有修改阻止、干净时二次确认;切换不丢数据

### Stage 6:聊天快捷指令 + Git 保存(中风险)
- 范围:5 个快捷按钮 + 指令可用性检查;`git:commit` + 确认窗口(文件清单/diff/敏感文件提醒)
- 验收:可用指令正常执行、不可用友好提示;/init /simplify 修改前提示;保存按钮二次校验、不 push、敏感文件提醒

### Stage 7:打包 + 开源准备
- 范围:清理依赖、electron-builder 配置、生成图标、MIT LICENSE、.gitignore 检查、敏感信息排查
- 验收:NSIS 安装包生成、安装后独立启动、数据在 userData;仓库无敏感文件;创建仓库/公开/push 前暂停等用户确认

## 6. 风险与缓解

| 风险 | 缓解 |
|------|------|
| Git checkout/commit 误操作丢数据 | 工作区检查 + 二次确认 + 不 reset --hard + 不 push |
| 删除文件夹误删 | 路径拦截(工作台/主目录/根目录)+ 输入名称确认 + 失败保留记录 |
| 原生模块/打包兼容 | 用 node:sqlite(Electron 内置),移除 better-sqlite3 |
| 语言切换遗漏文案 | 缺译回退中文兜底 |
| 敏感信息进仓库 | 开源前全量检查 + 发布需用户确认 |
| `/btw` 等指令可用性未知 | 实现时实测,不可用友好提示 |
| 托盘图标缺失 | 复用 Stage 7 生成的占位图标 |
| 关闭拦截导致「无法退出」 | 退出入口明确(托盘「退出应用」);活跃任务退出前二次确认 |
